C21 English Resources — Final
สำหรับ CyberStep 1.509.0

แพ็กอังกฤษแบบคัดลอกสองไฟล์ ใช้ทรัพยากรเดียวกับ v1.2

ติดตั้ง
1. ปิดเกมและตัวอัปเดต
2. สำรอง resources\etc.kar และ resources\kwt.kar เดิมไว้ต่างหาก
   หากมีสำรองต้นฉบับญี่ปุ่นแล้ว ให้เก็บไว้ ห้ามทับสำรองด้วยไฟล์ม็อด
3. คัดลอกโฟลเดอร์ resources ในแพ็กไปยังโฟลเดอร์เกม ยืนยันแทนที่สองไฟล์
4. เปิดเกมตามปกติ ไม่ต้องใช้ Agent หรือ Start-C21ThaiFull*.bat
หากติดตั้ง v1.2 อยู่แล้ว ไม่ต้องลงใหม่ ไฟล์เกมเหมือนกันทุกไบต์

ขอบเขต
- แปลพจนานุกรม UI และข้อความ KWT ที่รองรับเป็นอังกฤษ
- รวมชื่อค่าสถานะแบบสั้น ป้ายตั้งค่ากราฟิกแบบสั้น และ Hover Display
- คงชื่อ NPC และภาพต้นฉบับ
- ชื่อเควสต์ รายละเอียดเควสต์ และข้อความชิ้นส่วนที่อยู่นอกสองไฟล์นี้ยังเป็นภาษาเดิม
- ไม่เปลี่ยนมาโครที่ผู้เล่นบันทึกไว้ หรือไฟล์โปรแกรม/การตั้งค่าของผู้เล่น
- หากเคยลงภาพแปลจากแพ็กไทย ต้องคืน image.kar ต้นฉบับที่ตรงรุ่นแยกต่างหาก

ถอน
ปิดเกมแล้วคัดลอก etc.kar และ kwt.kar ต้นฉบับจากสำรองกลับเข้า resources
เก็บสำรองและโฟลเดอร์กู้คืนเดิมไว้จนกว่าจะตรวจว่าถอนสำเร็จ

รุ่นเกมและ Locale Emulator
ใช้กับ CyberStep 1.509.0 ตามต้นฉบับที่ตรวจไว้เท่านั้น ยังไม่ยืนยัน Steam/รุ่นอื่น
หลังเกมอัปเดต ต้องใช้แพ็กที่ตรงรุ่น ไม่ควรนำไฟล์เก่าทับทรัพยากรรุ่นใหม่
แพ็กอังกฤษไม่ต้องใช้ Locale Emulator
LE 2.5.0.1 เคยใช้เปิดเกมในเครื่องนี้ แต่ยังไม่มีผลทดสอบแพ็ก Final แยกกับ LE
แพ็กนี้ไม่ได้แก้การพิมพ์ไทยผ่าน LE; การเปิดเกมปกติเคยพิมพ์ไทยได้ตามรายงานผู้ใช้

การตรวจสอบ
ตรวจแฮชไฟล์เทียบ v1.2 และตรวจข้อมูลใน ZIP แล้ว
รุ่นก่อนหน้ามีภาพทดสอบในเกมจากผู้ใช้; การแก้ป้ายล่าสุดใน v1.2 ผ่านการตรวจออฟไลน์
ยังไม่ได้ตรวจทุกหน้าจอในเกม Final หมายถึงแพ็กส่งมอบขอบเขตนี้ ไม่ใช่แปลทั้งเกม 100%
